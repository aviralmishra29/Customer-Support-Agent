# Notes

Study notes, organized by topic, for revision later.

**Convention:**
- One subdirectory per broad topic (e.g. `rag/`, `langchain/`, `langgraph/`, `ollama/`).
- Inside each, one file per concept learned that day (e.g. `rag/chunking-and-overlap.md`, `langgraph/state-graph.md`).
- Each note file should stand alone for revision: what the concept is, why it exists, why we chose it here (if a decision was made), and any gotchas hit while testing it.
- `docs/progress.md` logs *what we did each day*; these notes capture *what we learned* — progress entries can link to the note file(s) written that day.
