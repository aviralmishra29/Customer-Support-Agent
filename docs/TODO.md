- [x] Structured error handling (LLM timeout/retry, vector DB down, tool failure) — 2026-10-11. **Tested real failure modes empirically first** (`tests/test_infra_failure_baseline.py`), not guessed: Ollama unreachable raises `httpx.ConnectError`; Chroma unreachable raises `chromadb.errors.InternalError` (base class `chromadb.errors.ChromaError`); SQLite missing-file AND real lock contention (tested with an actual competing `BEGIN EXCLUSIVE` connection, not just a bad path) both raise the identical `sqlite3.OperationalError` - one handler covers both. **Real gap found along the way:** no `ChatOllama(...)` instantiation anywhere in the codebase had a timeout configured - a hung/slow Ollama wouldn't raise any catchable exception at all, it would just hang the node forever;
